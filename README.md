
## Front-end Challenge Solution 

1. Clone the repo:

```bash
git clone git@github.com:filipacotrim/vizzuality-challenge.git
```

2. Move to the main directory:

```bash
cd legen-vizz
```

3. Run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

4. Visit [website](http://localhost:3000)!
